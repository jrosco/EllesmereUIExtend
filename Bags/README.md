# EllesmereUI Extend Bags

Read-only personal bank and optional character-inventory snapshots using **EllesmereUIBags** or **EUI Standalone Bags**, for Retail and WoW Forever.

## Install and open

Install the ZIP as `Interface/AddOns/EllesmereUIExtendBags/`. Enable either **EllesmereUI** and its **EllesmereUIBags** module, or **EllesmereUI: Standalone Bags** (`EUIStandaloneBags`, inspected against v9.4). No other Extend addon or separate Core addon is required. For source installs, copy `Bags/` to that folder and embed `Core/Core.lua`, `Core/Sync.lua` and `Core/Options.lua` under `Shared/`.

Standalone Bags disables itself when the full suite or another EUI standalone is enabled; Extend respects that guard and prefers the full suite when present. Without an active Bags host, no viewer/button or bank capture starts, a login message explains the requirement, and saved profiles/inventory remain intact. Standalone settings, category assignments, media and scrollbar helpers are read from that host, without global aliases or native settings migration. Switching hosts preserves Extend's saved profiles and bank snapshots, but uses the new host's current categories/display preferences. Update installed Extend addons together so their embedded shared core supports the standalone settings hub.

Includes its own icon for WoW's AddOns list in `Media/Icon.tga`.

The source TOC version is the placeholder `0.0.0`. GitHub release builds apply the history-derived version and selected alpha/beta/stable channel to the packaged TOC only; see [Releases](../docs/RELEASES.md#bags-source-version-and-release-channels). This source version is not proof of in-game verification.

- Open normal EUI bags and click the attached **Bank Snapshot** button below the window, or use `/ebags`.
- The button remains clickable before your first capture. Every time the viewer opens, it starts on the current character and clears the previous tab, scroll position and search. Without their snapshot, it opens an empty bag displaying **Visit the banker first**, even when other characters have snapshots.
- The selected character and dropdown show **occupied slots** beside each name when search is empty (a stack of 20 counts as one slot). While searching, this becomes the number of **matching slots**, still counting each stack as one. Both counts span the entire saved personal bank and captured reagent storage regardless of selected tab/category. Empty captured banks or searches with no matches show **(0)**; the uncaptured current character shows **(No snapshot)**. Choosing another character keeps the search and resets tab/category selection and scrolling. Clearing the search restores occupied-slot totals. There is no stacks-count label at the bottom of the window. Counts use the same literal item-name/ID search as the viewer; uncached names match only through the saved link/ID until item information arrives. Other characters' counts are calculated on opening the dropdown, not through background inventory scans.
- Click the **x** beside the search bar to clear its text and release keyboard focus. It appears while text is present, preserves the selected character/tab/category and resets scrolling to the top; clearing is locked during Edit Mode.
- **Extend Addons > Bags > Snapshot Bags** is the first settings tab and combines both modes' controls. **About** explains capture limits, search, tooltip behaviour and profiles. `/eextend` opens shared profiles. The viewer's top-right settings icon, next to switching, opens **Snapshot Bags** directly without closing the snapshot; Edit Mode and combat block navigation. Older hosts without plugin navigation show a disabled icon with an update explanation.
- **Enable Bank Snapshot viewer** defaults on. Turning it off blocks the bank footer button, header switching to bank and `/ebags`, but **does not stop bank capture or delete snapshots**. Bank stock still contributes to tooltips and combined search in Alt Bags. An open bank viewer switches seamlessly to enabled Alt Bags, or closes if neither mode is accessible. **Show Bank Snapshot button** separately controls only the footer entry; hiding it leaves the enabled viewer accessible through switching and `/ebags`. Its visibility preference is retained while the viewer is disabled.
- **Show snapshot counts in tooltips** is **off by default**, per Extend profile. A single muted-gold **Snapshot stock** heading covers both sources. Left labels are **Current**/**Other** when **Compress tooltip counts** is enabled (default), or named characters when disabled; right labels always read **Bags: quantity / Bank: quantity**. Zero for one source stays explicit; rows with both zero and sections without any stock are omitted. Named rows include realms, current player first, with class colours and bright quantities. Unknown classes use neutral grey until that character logs in. Opening/closing live bank or snapshot windows never overrides the selected format. Previously enabled bank or inventory tooltip preferences are combined into the shared switch; no inventory is copied.
- Tooltip quantities sum saved stacks by item ID across variants, not occupied slots. Bank counts include captured personal reagent storage; inventory counts require **Enable Alt Bags** and include its captured carried reagent bag. Missing/uncaptured sources contribute zero saved quantity, not a live inventory estimate. Disabling the bank viewer does not suppress bank counts. Equipment, Warband and guild storage are excluded; snapshots may be outdated until recapture. Other tooltips (equipment, chat links, currency and comparisons) remain unchanged. Retail uses item-tooltip processing; older clients use the supported item-tooltip script, or omit native EUI stock if neither is available. The snapshot viewer still supports explicit count rows and a text fallback without two-column tooltip support. Reset turns counts off and compression on without clearing inventory.
- For a low footprint, each source's tooltip counts use an item-ID index built lazily after loading/capturing snapshots. Repeated hovers do not scan live containers or revalidate every stored inventory; disabling the shared tooltip option releases both indexes. Carried-bag capture runs only when Alt Bags is enabled, with no continuous polling. Historical `bags` data, if present, is left untouched and unused; new inventory snapshots use the independent `inventories` section.
- The left sidebar shows **Tabs** and **Categories** together. Categories filter the selected bank tab; **All tabs** includes all captured storage and **All categories** clears the category filter. Category navigation works in every display, independently of Group by Category and List header collapse. Reopening resets navigation to All tabs/All categories on the current character.
- Category occupied-slot counts sit in a separate right-aligned label so long category names truncate without cutting off the count. Counts reflect the selected tabs, independent of search; the collapsed sidebar hides names and counts, keeping icons only.
- Click the sidebar arrow to collapse it to a narrow icon-only strip or restore labels. Sidebar tab and category buttons have no tooltips. Long navigation lists scroll separately with the mouse wheel. Collapse state starts expanded and is remembered per Extend profile across reopening/reload. Collapsing frees more space for items without changing your saved window size.
- Sidebar categories reuse EUI's category icons, including atlas icons, custom textures and its Forever icon substitutions. Unavailable atlas/helper support falls back safely; icons stay tooltip-free.
- **Window Scale** (50–150%, in 5% steps; default 100%) and **Frame Strata** are saved per Extend profile and shared between snapshot modes, not the attached buttons or EUI's live bags/bank. Strata choices match EUI: Background, Low, Medium, High and Dialog (default). Changing scale keeps the saved position; moving/resizing remains scale-aware. These controls are locked during EUI Edit Mode.
- **Group by Category** and **Snapshot display** are shared by both modes, alongside category collapse and all window preferences. The shared display setting offers **Match EUI** (default), **Grid**, **Compact** and **List**. Match EUI follows the corresponding live source: inventory for Alt Bags and bank for Bank Snapshot; the viewer button labels that source explicitly. Existing bank display/grouping preferences now apply to both modes; former per-alt preferences are unused. Grouping defaults off and applies within the selected tabs; **All tabs** groups across captured storage.
- Categories use the current EUI bag names, order, item assignments and disabled-category settings, including for alts and both sources. Quest/equipment-set membership is captured with each snapshot; older bank snapshots need a new banker visit for that information. Alt set gear uses the merged set-gear category rather than matching unrelated characters' set IDs. Missing category helpers fall back to **Other** without losing items.
- List follows EUI's configured column selection/order and shows reliable stored-link information (name, item level, required level, type, count and stack vendor value). Binding labels combine the item binding type with captured bound state; unavailable binding/upgrade-track information stays blank. The viewer uses EUI bank media, borders, fonts and icon zoom, but retains independent read-only buttons—not the actionable live bank frame.
- In List display, item-quality borders surround only the item icon; rows stay neutral. Hiding the icon column also hides its quality border.
- Snapshot item tooltips show the saved item's normal tooltip and optional stock counts, without tab/slot details or a read-only reminder footer. Items remain read-only.
- With **Group by Category** enabled in **List**, click a category header to collapse/expand its rows. Headers show an indicator and matching stack count. Collapsed categories are remembered per Extend profile across reopening/reload and shared across bank tabs/characters using the current EUI category identities. Grid/Compact ignore collapse state; resetting Bags settings expands all categories. EUI Edit Mode prevents collapse changes.
- Visit a banker on each character to capture their bank. Use the character dropdown to choose other captured banks or return to the current character (always listed first, even without a snapshot). The dropdown uses EUI's menu when available and a scrollable fallback on older EUI; selection is locked during Edit Mode. Use tab buttons to filter storage and search by item name or ID. All matching stacks occupy one continuous area: scroll with the mouse wheel or drag the right-hand scrollbar, without stack page arrows. Category blocks fill the available area rather than jumping to another page. Refreshes preserve the character and scroll position you are browsing; changing character, tab, search, grouping or display resets scrolling to the top.
- Scrolling reuses EUI's bank scrollbar helper when available, with a styled, template-free fallback for older EUI. Item buttons and category headings are clipped inside an addon-owned scroll frame; normal EUI bags/bank frames are untouched.
- Drag the viewer's heading to move it and the EUI-style grip beside the **bottom-right lock icon** to resize it. Double-click the grip to reset size without moving the window. The lock fixes **both position and size** and hides the grip; windows start unlocked. Each Extend profile remembers its own size, position and lock state across reopening/reload. Resizing reflows icon columns and adjusts the scroll area; switching displays never overrides your chosen size. Moving, resizing and changing the lock are disabled during EUI Edit Mode. Escape closes the viewer. Tooltips show stored item links, counts appear on icons, and the heading shows the last successful capture time.

## Snapshot behavior

Captures supported personal bank tabs/bags and separate reagent storage when exposed by the client. Warband, guild bank and carried reagent bags are excluded. Portable account-bank access does not capture personal storage. The viewer is a separate EUI-styled window; normal EUI bags/banking remain unchanged. Item icons have no item-use, transfer, drag, deposit or withdrawal actions.

Capture runs only while bank access is open, waits for two stable complete scans, and updates throughout the visit. Unavailable, throwing, restricted or incomplete data retains the last successful snapshot. Closing the bank stops scanning immediately; very rapid changes followed by immediate closure may therefore leave the previous snapshot. Empty banks are valid captures. Item names not yet cached can still be searched by stored link/ID and refresh when item data arrives.

`EllesmereUIExtendBagsDB` stores account-wide character snapshots separately from `EllesmereUIExtendBagsProfiles` (shared UI settings). Profile switches/reset never erase either source's inventory. Snapshots are local to this WoW installation/account's SavedVariables, not synced across computers or accounts. Unsupported database formats are preserved rather than migrated. Update installed Extend addons together when using the new Bags profile owner.

Character class identifiers are recorded at login and successful captures in this inventory database, independently from snapshot contents and shared UI profiles. Existing snapshots without class metadata remain usable with neutral-grey names.

## Alt Bags

- Enable **Extend Addons > Bags > Snapshot Bags > Enable Alt Bags**. It defaults **off**, per Extend profile. Log into each character with the option enabled to capture their backpack, equipped inventory bags and supported carried reagent bag. The current character is included. Equipped gear, bank, Warband and guild storage are excluded. Offline contents are the last saved snapshot, never live queries of another character.
- Capture starts at login/enabling and after inventory events. Two complete matching scans are required; transient, throwing, restricted or missing data retains the last good snapshot. Brief retries stop after success or eight seconds, and immediately on disable/logout; there is no permanent inventory polling. Empty inventories and removed inventory bags are valid captures. Missing APIs/enums disable new enablement with an explanation; existing snapshots and saved choices remain intact. A client without a reagent-bag enum captures supported standard bags only.
- The **Alt Bags** button sits immediately left of **Bank Viewer** below EUI bags. If the bank button is hidden or its viewer is disabled, Alt Bags occupies its right-hand position. Each snapshot mode has a top-bar switching icon when both modes are accessible. Switching does not close/reopen the shared window: it preserves selected character, search, position, size, scale and lock while clearing source-specific tab/category selection and scroll. Closing/reopening still starts on the current character with an empty search. `/ebags` opens Bank Snapshot only while its viewer is enabled.
- Both modes reuse EUI categories, shared display/grouping/List category collapse and the same read-only renderer. Disabling Alt Bags hides its buttons, stops capture and returns an open Alt Bags viewer to enabled bank mode, or closes when the bank viewer is also disabled, without deleting snapshots.
- While Alt Bags is enabled, searching either mode displays separately labelled **Inventory Bags** and **Bank Snapshot** sections for the selected character, including explicit missing-snapshot states. Search spans all storage in both sources (tab selection is temporarily disabled); an optional category filter applies to both. Character dropdown choices include characters captured in either source. Labels show **Bags: N / Bank: N** matching occupied slots, independent of category selection. Each stack counts once: two stacks of 20 are two matching slots, not 40. Clearing search restores the active source's occupied-slot totals and tab navigation.
- Inventory tooltip quantities use the shared **Show snapshot counts in tooltips** switch and are included only while Alt Bags is enabled. Disabling Alt Bags suppresses carried stock (displaying **Bags: 0**) while leaving available bank quantities and the shared tooltip preference intact. Compression applies identically to either snapshot mode, live-bank items and ordinary/detached EUI bags.

Public API: `EllesmereUIExtendBags`. UI settings use the singleton's `bags` section. Retail 12.1.0 and Forever 1.60.1 are packaging targets, not proof of in-game validation. See [Testing](../TESTING.md) and [Releases](../docs/RELEASES.md); both clients still require in-game verification.
